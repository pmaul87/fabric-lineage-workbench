# Security Policy

## Reporting a Vulnerability

Please do not report suspected security vulnerabilities through public GitHub issues.

Use one of these private channels instead:

1. GitHub Security Advisories for this repository, if enabled.
2. Direct private contact with the repository maintainer.

If you publish this repository, replace this section with the exact private reporting channel you want contributors to use.

## What to Include

Please include as much of the following as possible:

- A description of the issue and potential impact
- Affected files, scripts, or endpoints
- Reproduction steps
- Any environment or configuration prerequisites
- Proof-of-concept details, if available

## Disclosure Expectations

Please allow a reasonable amount of time for triage and remediation before public disclosure.

## Supported Versions

Security support is best-effort for the latest code on the default branch unless a separate support policy is published.
