# Support

## How to Get Help

Use GitHub Issues for bug reports, setup problems, and feature requests.

Before opening a new issue:

1. Review [README.md](README.md), [CUSTOMER_README.md](CUSTOMER_README.md), and [TEST_VERSION_README.md](TEST_VERSION_README.md).
2. Check existing issues to avoid duplicates.
3. Collect the command you ran, relevant environment details, and the exact error output.

Open a new request here: [New Issue](../../issues/new/choose)

## What to Include

- Reproduction steps
- Expected behavior
- Actual behavior
- Relevant logs or terminal output
- The environment you used, such as local dev, test-version deployment, or manifest publication

## Security Issues

Do not report security vulnerabilities in public issues. Follow the process in [SECURITY.md](SECURITY.md).
