# Code of Conduct

This project aims to provide a welcoming, respectful, and constructive environment for contributors and users.

## Expected Behavior

- Be respectful and professional.
- Assume good intent and focus on technical substance.
- Give actionable feedback.
- Keep discussions relevant to the project.

## Unacceptable Behavior

- Harassment, abuse, or personal attacks
- Discriminatory or hateful language
- Deliberate disruption of discussion or review processes
- Sharing private information without permission

## Scope

This code of conduct applies to project discussions, issues, pull requests, and other community spaces associated with this repository.

## Reporting

If you encounter unacceptable behavior, contact the repository maintainer privately using the channel documented in [SECURITY.md](SECURITY.md) or the repository profile/contact details.
